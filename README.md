# FitPulse — Modern Fitness Ecosystem

FitPulse is a high-performance, minimalist fitness tracking application designed to provide a seamless and visually striking experience for athletes and fitness enthusiasts. Built with a focus on high-contrast aesthetics and data clarity, FitPulse helps you track your workouts, manage your nutrition, and stay on top of your goals.

![FitPulse Preview](https://via.placeholder.com/1200x600/000000/B4D400?text=FitPulse+Modern+Fitness+Ecosystem)

## ✨ Core Features

-   **🚀 Dynamic Dashboard**: Real-time overview of your workout frequency, total duration, and calorie burn metrics visualized with interactive charts.
-   **🏃 Activity Tracking**: Log and monitor various workout types with precision, managing history and performance trends.
-   **🥗 Nutrition Planning**: Comprehensive meal tracking system to align your diet with your fitness objectives.
-   **🔔 Smart Notifications**: Integrated alerts system to keep you updated on milestones, reminders, and system updates.
-   **👤 Advanced Profiling**: Personalized user experience with profile management.
-   **🔒 Secure Authentication**: Modern, sleek login and registration interfaces for a frictionless entry.

## 🎨 Design System

FitPulse utilizes a unique **Lime & Black** high-contrast design system optimized for readability and energy.

-   **Primary Color**: `#B4D400` (Electric Lime)
-   **Background**: `#000000` (Deep Black)
-   **Typography**: 
    -   *Barlow Condensed*: For bold, high-impact headings.
    -   *DM Sans*: For clean, legible body text and UI components.
-   **Aesthetics**: Glassmorphism effects, smooth micro-animations, and a persistent navigation sidebar.

## 🛠️ Tech Stack

-   **HTML5 & CSS3**: Semantic structure and custom-variable-driven styling.
-   **JavaScript (ES6+)**: Core application logic and DOM manipulation.
-   **[Chart.js](https://www.chartjs.org/)**: Dynamic data visualization for activity trends.
-   **[Bootstrap Icons](https://icons.getbootstrap.com/)**: Minimalist iconography.
-   **Google Fonts**: Premium typography integration.

## 🚀 Getting Started

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/kemar-khan/fitness-tracker-frontend.git
    ```
2.  **Open the project**:
    Simply open `index.html` in your preferred modern web browser.
3.  **No dependencies needed**:
    FitPulse uses CDN links for external libraries (Chart.js, Bootstrap Icons), so no `npm install` is required for basic local development.
